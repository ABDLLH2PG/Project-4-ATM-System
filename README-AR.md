# 🏧 نظام الصراف الآلي (ATM) - المشروع الكامل 🚀

[ **🇺🇸 Read this project in English** ](./README.md)

تطبيق نظام صراف آلي احترافي تم تطويره بلغة **C++**، مصمم لمحاكاة العمليات البنكية الواقعية من خلال نهج تطويري منظم ومهيكل.

---

## 💡 فكرة المشروع
يهدف المشروع إلى توفير واجهة برمجية آمنة تسمح للعميل بتنفيذ عمليات بنكية ذاتية بعد التحقق من بياناته، مع ضمان تحديث أرصدة العملاء بشكل لحظي وآمن داخل ملف نصي لضمان بقاء البيانات بعد إغلاق البرنامج.

---

## 🛠 الأدوات والتقنيات المستخدمة
* ⚙️ **لغة البرمجة:** ++C.
* 📦 **هياكل البيانات:** استخدام `Structs` لتمثيل بيانات العميل، و `Vectors` لتخزينها ومعالجتها ديناميكياً في الذاكرة.
* 💾 **التعامل مع الملفات:** استخدام مكتبة `fstream` لقراءة بيانات العملاء من ملف `Clients.txt` وحفظ التحديثات بشكل دائم.
* 🧩 **هيكلية الكود:** البرمجة الإجرائية (Procedural Programming) عبر توزيع المهام على دوال متخصصة لضمان كود نظيف، مقروء، وقابل للصيانة.

---

## 📱 واجهات النظام والعمليات المتاحة
بعد تسجيل الدخول بنجاح، يتيح البرنامج للمستخدم الوصول إلى شاشات متكاملة:

* 🏠 **القائمة الرئيسية:** الواجهة المركزية للتنقل السريع بين جميع خدمات النظام.
* ⚡ **السحب السريع:** واجهة مخصصة لسحب مبالغ محددة مسبقاً (20، 50، 100، إلخ) بسرعة وكفاءة.
* 💵 **السحب العادي:** تتيح إدخال مبلغ مخصص للسحب، مع عمليات تحقق مدمجة (مضاعفات الرقم 5) والتحقق من توفر الرصيد.
* ➕ **الإيداع:** شاشة آمنة لإضافة أموال مباشرة إلى رصيد حساب العميل.
* 🔍 **الاستعلام عن الرصيد:** شاشة عرض منظمة لرؤية الرصيد الحالي المحدث.
* 🔓 **تسجيل الخروج:** إنهاء الجلسة الحالية بأمان والعودة لشاشة تسجيل الدخول.
