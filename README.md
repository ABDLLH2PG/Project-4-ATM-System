# 🏧 ATM System - Complete Project 🚀

[ **🇸🇦 Read this project in Arabic** ](./README-AR.md)

A professional ATM system application developed in **C++**, designed to simulate real-world banking operations through a modular and structured development approach.

---

## 💡 Project Concept
The project provides a secure interface allowing clients to perform essential banking operations after authentication. It ensures that account balances are updated in real-time within an external file, guaranteeing data persistence even after the program closes.

---

## 🛠 Technical Stack
* ⚙️ **Language:** C++
* 📦 **Data Structures:** Utilized `Structs` to define client profiles and `Vectors` for dynamic in-memory data management.
* 💾 **File I/O:** Leveraged `fstream` to read client data from `Clients.txt` and perform persistent updates.
* 🧩 **Code Architecture:** Built using **Procedural Programming**, distributing logic across specialized functions to ensure clean, readable, and maintainable code.

---

## 📱 System Interface & Operations
After a successful login, the system provides a comprehensive set of features:

* 🏠 **Main Menu:** The central hub for navigation, providing quick access to all system operations.
* ⚡ **Quick Withdraw:** A streamlined interface for rapid withdrawals of predefined amounts (20, 50, 100, etc.).
* 💵 **Normal Withdraw:** Allows users to input a custom withdrawal amount, with built-in validation (multiples of 5) and balance sufficiency checks.
* ➕ **Deposit:** A secure interface to add funds directly to the user's account balance.
* 🔍 **Check Balance:** A clean display screen to view the updated account balance.
* 🔓 **Logout:** Safely terminates the current session and redirects the user to the login screen.
